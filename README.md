# ポケモンチャンピオンズ 計算ツール

ポケモンチャンピオンズ対応の素早さ比較・ダメージ計算ツール。Next.js + TypeScript + Tailwind で構築、Vercel デプロイ前提。

## 機能

1. **素早さ比較** (`/speed`) — 複数ポケモンの素早さを種族値・性格・努力値・ランク・スカーフ・追い風・まひ込みで比較
2. **素早さ一覧表** (`/speed-table`) — ロスター全ポケモンの種族値・無振り・準速・最速・最速スカーフを表形式で並べ替え可能に表示
3. **ダメージ計算** (`/damage`) — 第9世代準拠フル。タイプ相性、性格、努力値、個体値、ランク、STAB、テラスタル、天候、フィールド、急所、一部特性・持ち物に対応
4. **ポケモン一覧 / 個別ページ** (`/pokemon`, `/pokemon/[slug]`) — ロスター閲覧、種族値、覚える技

## データソース

- ポケモン本体データ: [PokeAPI](https://pokeapi.co/) からクライアントサイドで取得
- ロスター: `src/data/roster.ts` に明示列挙 (2026年5月時点の公開情報に基づくおおよその構成)
- タイプ相性: 第6世代以降の表 (フェアリー追加版)
- 性格・ダメージ計算式: 第9世代準拠

## 開発

```bash
npm install
npm run dev
```

http://localhost:3000 でアクセス。

## ビルド

```bash
npm run build
npm run start
```

## Vercel デプロイ

GitHub にプッシュ後、[Vercel](https://vercel.com/) で本リポジトリをインポートするだけ。`vercel.json` が含まれているのでビルド設定は自動。

## ロスターの編集

ポケモンチャンピオンズのレギュレーション変更・追加ポケモン発表時は `src/data/roster.ts` を編集してください。各エントリは PokeAPI 互換のスラッグを使用します:

```ts
{ slug: "garchomp", ja: "ガブリアス" },
{ slug: "charizard-mega-x", ja: "メガリザードンX", isMega: true },
{ slug: "tauros-paldea-aqua", ja: "ケンタロス(パルデア・アクア)" },
```

スラッグの正確な値は `https://pokeapi.co/api/v2/pokemon/{slug}` でアクセスできます。

## 既知の制限

- 一部の特性 (例: あめふらし、ねつぼうそう、てきおうりょく以外のレア特性) は手動指定が必要 — 「特性」プルダウンで手動指定可能
- 連続技 (タネマシンガン等) の複数ヒット計算は1ヒット分のみ
- 守る・身代わり等の状況変化技の効果は計算外
- 「攻撃側 HP%」 はもうか/げきりゅう判定にのみ使用
